# SuGang — The Book of Days

## Sidebar & Goal

사이드바를 더 짙은 에스프레소 색으로 조정하고 접기·펼치기 버튼을 추가했다. 한글 소개 문구와 메뉴에 겹치던 별 장식은 제거했다. 메뉴는 시간표 / To-do / Goal 세 가지다.

학습 일지는 별도 메뉴에서 제거했으며 기존 실행 기록은 To-do에서 열람한다. Goal은 월·주간 성취 스탬프, 연속 실천 일수, 실제 기록 시간과 목표별 To-do 진행률을 보여준다. 회고·근거 집계·다음 계획 전달은 하단 펼침 영역에 보존했다.

764px 화면과 모바일에서 접기·펼치기, 세 메뉴 탐색, 실행 기록 접근, 완료 근거로 표시되는 스탬프, 주간 전환과 기존 To-do·회고 흐름을 격리된 브라우저로 확인했다. 프로덕션 빌드 통과. 실제 DB 내용은 변경하지 않았다.

## Espresso & Calligraphy

사용자의 추가 요청에 따라 커피·초콜릿·에스프레소의 짙은 색과 부드러운 라운드를 적용했다. 로고 및 영어 장식 문구는 Pinyon Script / Parisienne 필기체를 사용한다. 패널·버튼·드롭다운·타임라인에 같은 곡률과 은은한 그림자를 적용하고, 금빛 테두리와 종이 질감은 낮은 대비로 조정했다. 좁은 데스크톱에서 사이드바 간격도 정리했다.

추가 스타일 파일: app/espresso.css. 메뉴 이동·시/분 선택·캘린더 드래그·일간 완료·월간 스탬프·모바일 및 프로덕션 빌드 확인 완료. DB 데이터 변경 없음.

사용자 참고 이미지의 양피지, 오래된 서재, 펜촉, 밀랍 봉인 분위기를 바탕으로 적용했다.

- 양피지색 바탕, 짙은 잉크 갈색, 황동·금박빛 테두리.
- 가죽 책 표지처럼 어두운 사이드바와 장식 프레임.
- 영문 고전 서체, 한국어 명조체, The Enrollment Office와 A Personal Book of Days 같은 장식 문구.
- 직접 작성한 SVG 만년필·책·두루마리·모래시계 아이콘, 모서리 장식과 종이 질감.
- 성취 토끼는 기능을 유지하며 밀랍 봉인처럼 표현.
- 시간·카테고리 드롭다운, 폼, 타임라인과 월간 기록까지 공통 스타일 적용.

구현 위치: app/medieval.css, app/components/MedievalIcon.tsx, public/parchment.svg, public/flourish.svg.
참고 이미지의 콜라주와 워터마크는 앱에 직접 삽입하지 않았다. 스타일 변경으로 사용자 데이터를 수정하지 않는다.

타입 검사·빌드, 격리된 브라우저에서 최초 메뉴 이동·시간 선택·신청·중복 검사·시간 범위 드래그·일간 완료·월간 스탬프·모바일 화면을 확인했다.

## Journal edition (T07, 2026-10-29)

사용자 참고 이미지(가죽 트래블러스 노트, 장식 테두리 고지, 밀랍 인장, 코발트 우표)를 바탕으로 "다이어리 꾸미기" 방향으로 다시 정리했다. 이전 판이 탁해 보였던 원인 — 화면 전체의 베이지 그라데이션, 둥근 알약 버튼과 퍼지는 그림자, 서체 4~5종 혼용 — 을 걷어냈다.

- 바탕은 린넨(직물 결), 종이는 모서리 2px의 얇은 장 + 이중 실선 테두리. 그림자는 짧고 낮게.
- 강조색은 두 가지만: 밀랍 옥스블러드(주요 버튼·완료·오늘), 우표 코발트(수치·근거). 황동은 명판·클립 장식에만.
- 서체: Cormorant Garamond(영문 이탤릭·숫자, lining figures), Noto Serif KR(한국어 제목), Noto Sans KR(조작 UI), Pinyon Script(로고·한 줄 문구). @fontsource로 직접 제공.
- 사이드바: 가죽 + 박음질 + 황동 명판 로고. 메뉴 활성은 종이 인덱스 탭.
- 로그인: 린넨 위의 끈 묶은 가죽 다이어리와 장식 모서리 첫 장, 밀랍 인장.
- Goal 수치와 5일 합계·평균은 천공 테두리 코발트 우표, 실천한 날은 붉은 밀랍 인장.
- 장식 이미지(public/journal/*.svg, WaxSeal.tsx)는 모두 직접 그린 SVG. 참고 이미지·실제 우표·상표 문양은 넣지 않았다.
- 구현: app/journal.css(마지막에 로드, body.sg 범위). 기능·DB 변경 없음.
