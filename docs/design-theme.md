# SuGang — The Book of Days

## Espresso & Calligraphy

사용자의 추가 요청에 따라 커피·초콜릿·에스프레소의 짙은 색과 부드러운 라운드를 적용했다. 로고 및 영어 장식 문구는 Pinyon Script / Parisienne 필기체를 사용한다. 패널·버튼·드롭다운·타임라인에 같은 곡률과 은은한 그림자를 적용하고, 금빛 테두리와 종이 질감은 낮은 대비로 조정했다. 좁은 데스크톱에서 사이드바 간격도 정리했다.

추가 스타일 파일: app/espresso.css. 메뉴 이동·시/분 선택·캘린더 드래그·일간 완료·월간 스탬프·모바일 및 프로덕션 빌드 확인 완료. DB 데이터 변경 없음.

사용자 참고 이미지의 양피지, 오래된 서재, 펜촉, 밀랍 봉인 분위기를 바탕으로 적용했다.

- 양피지색 바탕, 짙은 잉크 갈색, 황동·금박빛 테두리.
- 가죽 책 표지처럼 어두운 사이드바와 장식 프레임.
- 영문 고전 서체, 한국어 명조체, The Enrollment Office와 A Personal Book of Days 같은 장식 문구.
- 직접 작성한 SVG 만년필·책·두루마리·모래시계 아이콘, 모서리 장식과 종이 질감.
- 성취 토끼는 기능을 유지하며 밀랍 봉인처럼 표현.
- 시간·카테고리 드롭다운, 폼, 타임라인과 월간 기록까지 공통 스타일 적용.

구현 위치: app/medieval.css, app/components/MedievalIcon.tsx, public/parchment.svg, public/flourish.svg.
참고 이미지의 콜라주와 워터마크는 앱에 직접 삽입하지 않았다. 스타일 변경으로 사용자 데이터를 수정하지 않는다.

타입 검사·빌드, 격리된 브라우저에서 최초 메뉴 이동·시간 선택·신청·중복 검사·시간 범위 드래그·일간 완료·월간 스탬프·모바일 화면을 확인했다.
