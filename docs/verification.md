# 첫 개발 버전 검증

## 수강신청 폼 분리 및 탭 기능

학습은 목표와 요일·시간 설정을 제공한다. To-do는 이름 자체를 내용으로 사용하고 목표를 제거했으며 마감일과 시간표 배치는 선택 사항이다. 시간 없는 To-do도 최초 신청 완료 시 할 일 목록에 저장한다. 시간 배치한 To-do는 연결 활동과 일정, 요일별 할 일을 함께 만든다.

활동 조회 / 신청, 신청 내역, 시간표 미리보기를 실제 탭으로 구현했다. 신청 내역은 선택 항목만 필터링하며 미리보기는 선택한 요일별 블록과 시간 미지정 To-do 개수를 보여준다. 입력 컨트롤은 작게 줄이고 시 선택 후 분 시계로 전환되는 단계를 표시했다.

격리된 브라우저에서 서로 다른 폼, 시간 미지정 To-do 생성, 탭 전환·미리보기, 시→분 선택, 컨트롤 높이 44px 이하, 기존 요일별 시간과 종료 제한 및 모바일을 확인했다. 타입·프로덕션 빌드 통과. 실제 사용자 DB 내용 변경 없음.

## 실제 수강신청 저장 실패 수정 및 Clock UI

브라우저 요청의 Origin(127.0.0.1)을 Next 내부 URL(localhost)과 비교해 정상 저장을 403으로 차단하던 문제가 있었다. 요청 Host를 기준으로 비교하도록 수정하고, 다른 출처는 계속 차단한다. 출처·버전 검사 테스트 추가로 총 7개 데이터 테스트가 통과했다.

원형 시계의 시/분 선택·드래그·오전/오후 및 분 직접 입력을 구현했다. 종료는 시작 이후만 선택할 수 있고 시작을 늦추면 종료를 자동 조정한다. 수강신청에서는 같은 시간 또는 요일별 다른 시간을 선택할 수 있다. 햄버거 토글과 브라운 가로 스크롤바를 적용했다.

실제 Neon의 격리된 UUID 공간과 별도 로컬 서버로 브라우저 수강신청→저장 HTTP 200→시간표 생성→새로고침 후 두 요일 시간 유지까지 검증했다. 검증 공간과 임시 자료를 삭제하고 공용 사용자 공간은 변경하지 않았다. 공용 API에는 오래된 버전 요청만 보내 409를 확인했으며 쓰기는 발생하지 않았다. 기존 메뉴·To-do·회고·캘린더·모바일 흐름과 프로덕션 빌드도 통과했다.

## SuGang UI 개선 — 2026-10-15

서비스 이름과 브라우저 제목을 SuGang으로 변경했다. 최초 제목은 나만의 시간표를 설정해요다. 수강신청 전에도 메뉴별 화면을 탐색할 수 있으며, 필요한 설정 안내와 수강신청 복귀 버튼을 제공한다. 시간 설정은 공통 시·분 드롭다운으로 변경했다.

764×668 브라우저에서 수강신청 전 메뉴 이동·복귀, 공통 시간 선택(10:07), 이름과 제목을 검증했다. UI 테스트는 API를 격리하여 실제 사용자 DB를 변경하지 않는다. 타입 검사·빌드·6개 데이터 테스트 통과.

## Neon 연결 확인 — 2026-10-15

사용자가 .env.local에 연결 정보를 입력했다. 비밀값을 출력하지 않고 형식을 확인한 뒤 002_app.sql과 003_calendar.sql을 실제 Neon에 적용했다.

서버 재시작 후 /api/state의 저장·재조회·중복 요청 처리를 실제 Neon에서 검증했다. 기존 상태를 그대로 사용하여 검증했으며, 사용자 내용을 바꾸거나 가상 활동·학습 기록을 추가하지 않았다. 브라우저의 서버 DB 연결됨 표시와 미리보기 경고 제거를 확인했다. 아래의 연결 대기 문구는 이전 검증 시점의 기록이다.

## 통과

- TypeScript 검사, Next.js 프로덕션 빌드.
- 모델 테스트 4개: 서울 날짜·삭제 제외·막힘 distinct·집계, 이력 보존, 잘못된 참조와 중복 요청, PostgreSQL 저장·재조회·중복 요청·충돌·롤백.
- 실제 Edge 브라우저: 활동과 카테고리 등록 → 최초 설정 완료 → 반복 시간 배치 → 할 일 등록 → 실제 기록 → 완료 → 회고 → 다음 계획.
- 스크립트 형태 입력의 글자 표시, 브라우저 런타임 오류 없음.
- 390px 모바일 가로 넘침 없음, 미리보기 새로고침 초기화.
