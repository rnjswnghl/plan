# 실제 5일 사용 기록 — 시작 전

질문 초안: 정해진 공부 시간을 두 구간으로 나누면 하루 실제 학습 시간이 늘어나는가?
지표: 하루 실제 학습 시간(분). 실제 실행 기록의 minutes 합계. 계획 시간이나 To-do 개수와 섞지 않습니다.
날짜: Asia/Seoul, 실행 시작일 기준. 하루 합계는 기록별 minutes 합, 5일 평균은 다섯 날짜 합계/5, 표시는 소수 첫째 자리 반올림. 기록이 없으면 0으로 단정하지 않고 미기록으로 표시하고 최종 5일 모두 실제 기록 후 계산합니다. 중복 requestKey는 서버에서 거절하고 기존 실행 기록을 수정·삭제하지 않습니다. 긴 값은 원본 보존 후 사유를 기록합니다. 주 시작은 월요일.

- 1일차: 실제 사용 후 기록. 날짜/계획/실제 분/근거 기록 ID.
- 2일차: 같은 지표와 계산법.
- 규칙 변경: 반드시 2일차 기록 후~3일차 기록 전. 변경 시각, 1·2일차를 가리키는 근거, 바꾸는 계획 규칙과 이유를 저장.
- 3~5일차: 같은 지표·단위·계산법. 결과가 나빠져도 보존.
- 마지막: 원본 다섯 날짜의 분을 손으로 더한 값과 화면 합계·평균 대조.

현재는 기록을 시작하지 않았습니다. QA/예시 자료로 채우거나 과거 날짜로 꾸미지 않습니다. 질문과 규칙은 사용자가 실제 사용할 계획에 맞춰 1일차 전에 확정합니다.

## 화면에서 확인하는 곳

Goal 탭 → 5일 관찰. 1일차 날짜를 고르면 위 규칙 그대로 다섯 날짜 값·합계 식·평균을 보여줍니다. 지표 버튼은 `실제 학습 시간(분)`이 기본이며, 플랫폼 단위를 `완료 과제 수(개)`로 고르면 `완료한 To-do`로 바꿔 같은 화면에서 셉니다. 1일차 전에 둘 중 하나로 고정하고 5일 동안 바꾸지 않습니다. 계산 규칙 테스트: tests/observation.test.ts.

## 시연용 예시 계정 (실제 기록 아님)

`scripts/seed-demo.ts`는 시연 계정 하나와 **오늘로 끝나는 5일 예시 기록**을 만듭니다. 모든 항목 제목에 `[예시]`가 붙고 기록 시각은 스크립트가 정한 과거 시각이므로, 플랫폼의 5일 관찰 제출 근거(서로 다른 날 실제 기록)로 쓰지 않습니다. 화면·합계·평균이 손 계산과 맞는지 보여주는 용도입니다(예: 70 + 85 + 105 + 115 + 110 = 485, 평균 97).

실행(사용자 PC, .env.local에 Neon 값): `node --env-file=.env.local node_modules/tsx/dist/cli.mjs scripts/seed-demo.ts demo@sugang.test` → 비밀번호는 숨김 입력.
